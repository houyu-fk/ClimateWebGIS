# ClimateWebGIS 气象数据可视化平台

这是一个基于 **FastAPI + Vue 3 + Leaflet** 构建的专业气象数据可视化分析平台，旨在为气象科研与数据分析提供直观、高效的交互式 WebGIS 解决方案。

## 🚀 项目亮点

*   **智能 GIS 渲染**：利用 Leaflet 与 PostGIS，实现全国气象站点的动态空间渲染，支持专题图层切换。
*   **交互式可视化**：内置基于 ECharts 的气象数据统计分析面板，支持折线图自动冷暖色渐变渲染。
*   **空间分析能力**：一键开启热力分布图，基于站点气温实现科学的空间插值分析。
*   **全流程 CRUD 管理**：提供后台管理控制台，支持气象站点数据的实时增、删、改、查。
*   **用户互动社区**：构建了完整的用户身份认证系统，支持用户对站点及平台进行评价，实现数据共建。
*   **专业交互设计**：采用现代侧边栏布局，提供全局站点搜索与“上帝视角”地图平滑飞行定位功能。

## 🛠 技术栈

*   **后端 (Backend)**: Python, FastAPI, PostgreSQL (PostGIS), SQLAlchemy
*   **前端 (Frontend)**: Vue 3, Vite, Element Plus, Leaflet, ECharts, Axios
*   **数据可视化**: leaflet.heat (热力图插件)

## 📋 功能模块

1.  **站点地图搜索**：支持名称/站号模糊搜索，点击自动飞行定位并加载站点详情。
2.  **气温专题图**：自动根据年均温对站点进行颜色分级渲染，并配有专业图例。
3.  **数据统计面板**：左侧一键弹出气温区间柱状图，实时统计站点分布规律。
4.  **个人信息中心**：支持用户个性化设置（昵称、所在地、密码修改等）。
5.  **站点管理后台**：管理员可通过可视化表格直接管理气象站点数据库。

## 📦 快速部署

### 后端配置
1. 安装依赖：`pip install fastapi uvicorn psycopg2-binary pyjwt`
2. 配置数据库连接：在 `main.py` 中修改 `DB_CONFIG` 为本地 PostgreSQL 数据库参数。
3. 启动服务：`python -m uvicorn main:app --reload`

### 前端配置
1. 进入前端目录：`cd frontend`
2. 安装依赖：`npm install`
3. 启动开发环境：`npm run dev`
